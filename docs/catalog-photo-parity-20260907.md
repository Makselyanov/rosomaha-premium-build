## Граница изменения

Проверены 13 позиций. Изменяются только галереи и миниатюры в products.ts, удаляются неиспользуемые импорты. Не меняются цены, характеристики, цвета, опции, формы, интеграции или CRM. Все действующие страницы и статьи сохраняются.

Точное сопоставление хранится в `src/data/product-photo-sources.json`: модель, URL источника, время проверки, фото источника, локальный файл и SHA-256. Для ПРО сохранён размер официальных превью 520px; увеличение разрешения не входит в эту работу.

## Проверки

- `npm run test:catalog-photos`: полный охват моделей, галереи, миниатюры, контрольные суммы. Эта проверка также выполняется перед сборкой.
- `npm run audit:catalog-photos`: независимая повторная загрузка галерей rosomaha-rus.ru; любое расхождение блокирует успешный результат. Автоматически данные не меняет.
- `npm run audit:catalog-parity`: цены и характеристики остаются согласованными с источником.
- `npm run build`: сборка и проверка индексируемого HTML.

Изменения прошли независимое чтение исходников и проверку сопоставления 13 сохранённых HTML-страниц. Артефакты проверки находятся в ignored `.codex_tmp/photo-evidence/` рабочего дерева `photo-parity-20260907`.
